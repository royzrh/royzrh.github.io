隐私政策

最近修订日期：2026年11月28日

本站重视个人信息与隐私保护。本政策说明 Roy Zhao（赵润涵）运营的个人网站如何收集、使用、保存、共享及保护个人信息，以及您如何管理个人信息和行使相关权利。

本政策适用于本站各访问域名及其关联页面，包括博客、研究、相册、旅行游记、时刻、留言及账号服务。本站公开内容无需注册或登录即可浏览。

一、个人信息与适用范围#

个人信息是指与已识别或可识别的自然人有关的信息。电子邮箱、账号标识、网络 IP 地址以及能够与个人关联的其他数据，均按其性质及适用法律进行处理。无法识别特定个人且无法复原的匿名化信息，不属于个人信息。

本站根据功能所需处理个人信息，并区分公开展示的信息、账号及业务数据和汇总统计信息。您可以选择不提供非必要信息；如不提供特定功能所需的信息，该功能可能无法使用，但不影响公开内容的正常浏览。

三、信息公开与访问统计#

公开信息#

公开评论、留言、回复及其他公开内容可能展示昵称、头像、个人网站、发布时间及相关互动信息。用户主动公开的文字、图片或个人资料可能被其他访客查看、保存或引用。登录邮箱不随公开评论展示。

非公开留言及其他受限内容按照相应功能的访问权限展示；有管理权限的运营者可在维护、审核及处理反馈所需的范围内访问相关内容。请勿在公开内容中披露您或他人的敏感个人信息。

访问统计#

本站在 royzhao.cn 及其 www 子域名记录访问统计，以北京时间为统计基准。未登录访客按网络 IP 地址识别，登录访客按账号标识识别。匿名 IP 每日最多计入十次访问，管理账号共享每日十次访问额度，其他登录账号不设每日访问次数上限。

访问去重记录保存经带密钥哈希运算转换的标识、统计类别、日期及计数。该转换用于降低直接识别风险，并不等同于对个人信息进行不可逆匿名化。去重记录滚动保留最近365天，过期记录在新增统计时清理。公开页面仅展示汇总统计结果。网络服务提供商可能另外保存其运行日志，该期限与本站访问去重记录的期限不同。

四、个人信息的共享与第三方服务#

为提供账号、数据存储、邮件及网站分发等功能，本站使用下列第三方服务：

服务处理用途
Supabase ↗账号认证、数据库、文件存储及访问统计
Resend ↗邮件验证及文章订阅通知
Cloudflare Workers ↗后端接口及后台身份验证
Vercel ↗网站托管与内容分发
GitHub Pages ↗网站托管与内容分发

有关服务提供商可能因提供服务而处理必要的账号信息、电子邮箱、网络请求或业务数据。相关处理亦受适用的服务协议、隐私政策及法律要求约束。第三方服务处理的数据与本站公开展示的信息并不相同。

除实现上述功能所需、经您授权或适用法律允许或要求的情形外，本站不擅自向其他主体披露您的非公开个人信息。在履行法定义务、处理合法的监管或司法要求、维护网络安全或保护相关主体合法权益确有必要时，本站可能依法处理或披露必要信息。

本站链接至第三方网站或加载第三方提供的资源时，相关网站或服务可能独立处理您的网络请求及其他信息。第三方网站的个人信息处理活动适用其自身隐私政策。

五、信息保存与安全保护#

本站根据各项功能的实际运行、内容维护及适用法律要求保存个人信息。除第三节所述的访问去重记录外，账号资料、互动内容、上传文件、订阅记录及邮件发送记录的保存期限根据处理目的及实际管理需要确定。

删除或撤回公开内容后，部分内容可能以隐藏状态保存，用于内容管理、纠纷处理或恢复。停止公开展示并不必然意味着服务器记录已经删除。您可以通过本政策所列联系方式提出删除请求。

本站采用身份验证、数据库访问权限控制及 HTTPS 加密传输等技术措施保护账号及业务数据，并通过权限限制降低未经授权访问、泄露、修改及丢失的风险。任何网络传输及存储方式均无法保证绝对安全；如发生个人信息安全事件，本站将依法采取必要的处置措施，并在适用法律要求时履行告知义务。

六、Cookie 与本地存储#

本站使用浏览器本地存储、会话存储及相关技术支持网站功能，包括：

  • 保存登录会话及认证状态；
  • 记忆主题模式和部分界面偏好；
  • 缓存部分页面数据，减少重复加载；
  • 在后台认证流程中使用必要的 Cookie。

您可以通过退出登录、清除站点数据或调整浏览器设置管理上述信息。限制或清除相关存储可能导致登录状态丢失或部分功能无法正常使用。清除浏览器数据不会自动删除服务器端保存的个人信息。

七、您的个人信息权利#

在适用法律规定的范围内，您有权了解个人信息处理情况，并请求访问、复制、更正、补充、删除个人信息、限制相关处理或撤回同意，以及依法请求注销账号。

您可以通过账号设置管理头像、个人网站及订阅状态，通过相应功能管理本人发布的内容。文章通知可在账号设置中关闭，也可通过通知邮件中的退订链接取消。撤回同意不影响撤回前依法进行的处理。

如需行使其他个人信息权利，请通过本政策所列邮箱提出请求。本站可能要求提供核实身份及定位相关数据所必要的信息，以避免未经授权的查询或删除。本站将依法处理请求；依法需要继续保存或暂时无法删除的信息，将按照适用法律处理。

您亦可依法向有管辖权的个人信息保护监管机构反映相关问题。

八、未成年人保护#

本站以公开知识分享和个人记录为主要内容，并非专门面向儿童的服务。未成年人使用需要提交个人信息的功能时，应遵守适用法律；依法需要监护人同意的，应在取得同意后使用。

如监护人发现未成年人的个人信息在未经必要授权的情况下被提交至本站，可联系本站提出查询、更正或删除请求。本站将核实并依法处理。

九、个人信息的跨境处理#

本站使用具有全球基础设施的第三方服务。根据实际部署、网络路由及服务配置，个人信息可能在您所在国家或地区之外被传输、存储或访问。

相关处理应遵守适用的数据保护及跨境传输要求。对于依法需要另行告知、取得单独同意或履行其他程序的情形，本站将按照适用法律处理。

十、政策更新与联系方式#

本站可根据功能调整、个人信息处理方式及适用法律的变化修订本政策，并在本页面公布修订版本及日期。涉及个人信息处理目的、方式或范围的重大变化时，将依法采取相应的告知措施，并在必要时重新取得同意。
