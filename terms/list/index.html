技术架构

本站基于 Astro 框架，在 Axi Theme 开源主题的基础上进行了大量修改，包括页面设计、组件重构、功能拓展等。后端服务依托 Supabase 与 Cloudflare Workers，支持内容管理与发布、统一身份认证、用户互动及邮件订阅。网站采用多语言设计与响应式布局，通过自动化构建流程部署至多个平台。
